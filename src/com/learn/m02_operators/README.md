# m02 运算符

运算符是对数据进行“计算”和“判断”的符号。本模块覆盖五大类常用运算符。

## 学习目标

- **算术运算符** `+ - * / %`：尤其理解整数除法（结果只保留整数）和取余 `%`。
- **关系运算符** `> < >= <= == !=`：结果是 `boolean`（true / false）。
- **逻辑运算符** `&& || !`：组合多个条件，并理解“短路求值”。
- **位运算符** `& | ^ ~ << >>`：直接对二进制位操作。
- **三元运算符** `条件 ? 值1 : 值2` 与**自增自减** `++ --`。

## 留空方式说明

本模块仍以“**把占位值改成正确的表达式**”为主：你只需把 `int x = 0;` 里的 `0` 换成提示要求的表达式即可。
