# m01 基础语法与基本类型

万事开头难，但 Java 的第一步其实很简单。本模块带你认识一个 Java 程序最基本的样子。

## 学习目标

- 知道每个程序都从 `main` 方法开始运行，并会用 `System.out.println` 打印内容。
- 理解「变量」就是给数据起名字、存起来备用的容器。
- 认识 Java 的**八种基本类型**：`byte short int long float double char boolean`。
- 会写各种**字面量**（数字、字符、布尔值的直接写法）。
- 理解**类型转换**：小范围自动变大范围，大范围转小范围要强制转换且可能丢失精度。

## 关卡清单

| 关卡 | 文件 | 目的 |
|------|------|------|
| Ex01 | `Ex01_HelloWorld.java` | 打印第一行文字，认识 main 与 println |
| Ex02 | `Ex02_Variables.java` | 声明变量、赋值、打印 |
| Ex03 | `Ex03_PrimitiveTypes.java` | 八种基本类型各来一个 |
| Ex04 | `Ex04_Literals.java` | 下划线、十六进制、二进制、科学计数法等字面量写法 |
| Ex05 | `Ex05_TypeCasting.java` | 自动类型转换与强制类型转换（精度丢失） |

## 留空方式说明

本模块是第一站，留空采用**最简单的「直接改值 / 补一行」**方式：你只需要把占位的值或文字替换成正确内容即可，先不用关心方法、返回值这些概念。从 m05 模块开始，会出现需要补全「方法体」的练习。

## 学完自测

- `main` 方法的完整写法是什么？为什么字符串要用双引号括起来？
- `int` 和 `double` 有什么区别？把 `3.99` 强制转成 `int` 会得到几？
- `long` 字面量为什么要加 `L`？`float` 字面量为什么要加 `f`？
