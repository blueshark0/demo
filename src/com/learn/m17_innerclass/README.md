# m17 内部类与匿名类

类不一定要单独写在自己的文件里，它可以“嵌”在另一个类里、甚至嵌在方法里，还可以“没名字就地写出来”。本模块带你认识四种常见形态：成员内部类、静态嵌套类、局部内部类，以及用匿名类实现抽象类。

## 学习目标

- 区分成员内部类与静态嵌套类：是否依附外部对象、能否访问外部非静态字段。
- 掌握成员内部类的创建写法（必须借助外部对象）。
- 认识局部内部类：只在方法内可见，能捕获“事实最终”的局部变量。
- 用匿名类就地实现抽象类，并理解它与 Lambda 的适用边界。

## 小贴士

- “成员内部类靠外部对象创建、静态嵌套类自己就能创建”，记住这一条就抓住了二者的核心区别。
- 局部类和匿名类捕获的局部变量必须是“事实最终”的：赋值后不再改动，否则编译不过。
- Lambda 只服务于“单抽象方法的函数式接口”；遇到抽象类或多个抽象方法，就该想到匿名类。

## 学完自测

- 为什么成员内部类不能脱离外部对象单独创建，而静态嵌套类可以？
- 静态嵌套类为什么读不到外部类的非静态字段？
- “事实最终（effectively final）”是什么意思，它为什么会影响局部类/匿名类？
- 什么情况下只能用匿名类、用不了 Lambda？
