# m20 正则表达式

正则表达式是一套“描述字符串长相”的规则，用来做格式校验、查找、替换和切分。本模块衔接 m06 的字符串基础（`split`、字符串方法），带你认识元字符、量词、字符类，以及 `Pattern`/`Matcher` 的查找与分组。

## 学习目标

- 用整串匹配判断字符串是否符合某个格式（元字符、量词 `{n}`、字符类 `[...]`）。
- 用 `Pattern` 编译正则、用 `Matcher` 在文本中反复查找，并用圆括号分组取出各部分。
- 用基于正则的“替换所有”与“只替换第一处”改写字符串。
- 把正则当作分隔符做更聪明的切分，一并去掉分隔符两侧的空白。
- 牢记：Java 源码里写正则时，反斜杠要写成两个（如一位数字写成 `"\\d"`）。

## 小贴士

- 整串匹配是“全有或全无”：多一个或少一个字符都不算匹配；查找则是“在文本里挑出符合的片段”。
- 分组从 1 开始编号，整个匹配是第 0 组。
- 替换与切分都不改原字符串，而是返回新结果。
- 反斜杠一定写两个，这是初学者最常踩的坑。
