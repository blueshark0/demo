# m03 控制流

程序默认从上往下逐行执行。控制流语句能让程序“做选择”和“重复做”，是写出有逻辑的程序的关键。

## 学习目标

- **分支**：`if / else if / else` 根据条件走不同的路；`switch` 做多值匹配。
- **循环**：`while` 在条件成立时反复执行；`for` 适合“循环固定次数”。
- **循环控制**：`break` 提前跳出循环，`continue` 跳过本次进入下一次，以及带标签跳出多重循环。

## 留空方式说明

本模块以“**补全条件或循环体内的一句话**”为主，占位写成 `false` 或空循环体，运行后结果会“不对”，提醒你那里还没写。
