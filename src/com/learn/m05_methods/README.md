# m05 方法

方法（method）是一段“起了名字、可以反复调用”的代码。它能把复杂程序拆成小块，让代码更清晰、可复用。

## 学习目标

- 定义方法与调用方法；理解“参数（输入）”和“返回值（输出）”。
- **方法重载**：方法名相同、参数不同，可以并存。
- **递归**：方法调用自己来解决问题（如阶乘）。
- **可变参数** `int... nums`：让方法接收任意个数的参数。

## 留空方式说明

**从本模块开始，留空的是“方法体”。** 未补全的方法体里写了一行
`throw new UnsupportedOperationException(...)`，运行时会抛出异常来提醒你
“这个方法还没实现”。你的任务就是把那行替换成正确的实现。
